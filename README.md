# David Bedolla Robotics Portfolio

[Visit the portfolio](https://bedolladavidphd.github.io/)

A static, trilingual portfolio focused on robotics software engineering, real-time control, mobile manipulation, rehabilitation robotics, motion planning, and learning-based control.

## Highlights

- Curated English, Spanish, and French content
- Responsive light and dark themes
- Applied robotics case studies with vertical video demonstrations
- Interactive manipulator and aerial-system simulations
- Publications, professional experience, technical skills, and education
- Downloadable current CV

## Technology

The portfolio is implemented with HTML, CSS, and JavaScript and is deployed through GitHub Pages. Interactive simulations run in the browser without a server-side runtime.

## Public artifacts

This repository contains the deployed website assets and the current CV PDF. Editable document sources, document generators, maintenance utilities, internal review material, and private application documents are intentionally excluded from the public repository.
